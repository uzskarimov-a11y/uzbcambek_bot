# Instagram / YouTube Video Downloader Bot

Foydalanuvchi Instagram yoki YouTube havolasini yuborsa, bot videoni
yuklab, Telegram orqali qaytarib yuboradi.

## Render.com'da ishga tushirish

1. Yangi "Private Service" yarating, shu GitHub repo'ni ulang.
2. Build Command: pip install -r requirements.txt
3. Start Command: python bot.py
4. Environment bo'limiga BOT_TOKEN nomli o'zgaruvchi qo'shing
   (BotFather'dan olingan yangi token).
5. Deploy qiling.

## Eslatma

- Telegram bot orqali fayl yuborish limiti ~50MB. Undan katta
  videolarni bot yubora olmaydi.
- Faqat ochiq (public) yoki o'zingizga tegishli kontentni yuklang —
  mualliflik huquqi va platforma qoidalariga rioya qiling.
- Instagram ba'zan botlarni cheklashi mumkin (login talab qilishi);
  bunday holatlarda YouTube havolalari barqarorroq ishlaydi.
